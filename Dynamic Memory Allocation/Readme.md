#### What is Dynamic Memory Allocation ?

--> Dynamic Memory Allocation is a process of allocating memory at runtime.

#### Why do we need Dynamic Memory Allocation ?

--> We need Dynamic Memory Allocation because we can't predict the size of the data at compile time.

#### How to do Dynamic Memory Allocation ?

--> We can do Dynamic Memory Allocation using new and delete operators.

```cpp
    int *p = new int;
    *p = 10;
    delete p;
```

#### What is the difference between static and dynamic memory allocation ?

--> Static Memory Allocation is a process of allocating memory at compile time.

--> Dynamic Memory Allocation is a process of allocating memory at runtime.
